# Mafia Life Simulator

BitLife tarzı, Türkçe bir mafya hayat simülasyonu. Sokaktan tahta bir ömür.
Tek dosyalık HTML oyun: `index.html`.

Oynamak için GitHub Pages adresini Safari'de aç ve "Ana Ekrana Ekle" de.
Kayıtlar cihazın kendi hafızasında (localStorage) tutulur.

İnternetsiz oynama: Oyunu bir kez internet varken açman yeterli; `sw.js` oyunu telefona kaydeder, sonra uçak modunda da açılır.
